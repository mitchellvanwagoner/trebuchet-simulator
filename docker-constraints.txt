# Pins for the Docker image build only (see Dockerfile) so published GHCR
# images are reproducible; local dev installs stay unpinned per pyproject.toml.
# Versions mirror the development venv. llvmlite is pinned alongside numba
# because the two are tightly version-coupled.
#
# Keep streamlit in step with the venv the dashboard is developed against:
# web/theme.py pins the one-screen layout to Streamlit's internal DOM (the
# stMainBlockContainer / stLayoutWrapper / stColumn test ids, plus :has()
# selectors keyed on st-key-* container classes). Those are private API, so a
# container running a different Streamlit than the one the CSS was verified on
# can render a broken layout while local dev looks correct.
#
# Every version here has a cp312 manylinux wheel for x86_64 and aarch64, which
# is what the python:3.12-slim base needs to install without building from
# source.
